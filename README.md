# WebX - Clean & Modern Landing Page

## Overview
WebX is my first complete website project, created to experiment with **grids, spacing, colors, and interactive functionalities**. The goal of this project was to practice front-end development while applying **modern UX and UI principles** in a clean and minimalistic design.

## Features
- **Responsive Grid Layouts**: Built with Bootstrap to ensure a seamless experience on desktop, tablet, and mobile.  
- **Intelligent Spacing & Alignment**: Careful use of padding, margins, and white space for a balanced visual hierarchy.  
- **Adaptive Typography**: Text scales dynamically for readability across all devices.  
- **Color System**: Clean and modern color palettes applied consistently across the design.  
- **Interactive Contact Form**: Simple form layout prepared for PHP integration with basic security measures.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- PHP (for contact form functionality)
- JavaScript (for interactive features)

## Purpose
This project was created as a learning experience to explore **layout techniques, UX/UI design, and basic back-end integration**. It also serves as the first showcase of my work for my portfolio.
